CRISP-DM Machine Learning Methodology

Cross-Industry Standard Process for Data Mining (CRISP-DM) provides a structured lifecycle for feature selection and regression modeling:

1. Business Understanding: Maximize venture profit predictability while maintaining an interpretable model for executive decision-making.
2. Data Understanding: Examine 50 records of R&D, Administration, and Marketing expenditures alongside State categorical attributes.
3. Data Preparation: One-Hot encode State using drop_first=True (California dropped as reference) to prevent the Dummy Variable Trap (multicollinearity).
4. Modeling: Evaluate 5 feature selection algorithms across k=1 to 5 to explore model simplicity vs. explanatory capacity.
5. Evaluation (Occam's Razor): Test RMSE reaches its global minimum at k=2 ($8,198.80). Beyond k=2, adding Administration or State introduces parameter variance without improving test generalization, creating the overfitting cliff at k=5 ($9,137.99).
6. Deployment: Ship static interactive dashboard with what-if simulator and automated batch prediction export.
